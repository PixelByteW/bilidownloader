# B站视频下载器 (BiliDownloader)

一个 Windows 桌面应用，用于下载 B 站（bilibili.com）视频，支持合集、系列、收藏夹全量展开与批量导入。

> 仅供个人学习使用，请勿用于商业用途或传播下载内容。

## 功能亮点

- **全类型支持**：普通视频、多P、合集(剧集)、用户系列、收藏夹
- **批量导入**：一次粘贴多行链接，坏链接自动跳过并标注行号
- **任务搜索**：大合集中按标题/BV号 实时过滤，快速定位目标视频
- **失败重试**：单个任务失败自动重试并跳过，不阻塞后续下载
- **画质独立设置**：每个任务可单独指定画质与编码（双击任务行）
- **快速下载**：curl_cffi 多分片并发（单任务线程数可调，默认 8）
- **灵活命名**：模板变量组合（画质/标题/分P/序号等），一键预设
- **无登录依赖**：公开视频无需登录即可下载；登录后可提升画质上限

## 快速开始

### 方式一：直接使用打包版

从 Releases 页面下载 `BiliDownloader.exe`（约 80MB，已内嵌 ffmpeg），双击运行即可。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

需要 ffmpeg（高画质合并用）：下载静态构建放入 `ffmpeg/ffmpeg.exe`，或放到程序目录。

### 命令行（调试用）

```bash
python main.py --cli <视频链接> [输出目录] [画质] [编码]
```

## 使用说明

1. 粘贴链接（支持多行）→ 点"解析"，任务列表展示所有视频
2. 勾选需要的任务（或"全选"），点"开始下载"
3. 命名模板支持：`{title}`分P标题、`{video}`主标题、`{p}`分P序号、`{p2}`单P为空、`{quality}`画质、`{codec}`编码、`{bvid}`BV号、`{n}`导入顺序号(01起)

## 技术栈

- Python 3.12 + Tkinter + ttkbootstrap
- yt-dlp（下载引擎）+ curl_cffi（分片加速）
- PyInstaller 打包为单文件 exe

## 项目结构

```
├── main.py            # 入口
├── app/
│   ├── ui.py          # 界面
│   ├── bili_api.py    # 解析（视频/合集/系列/收藏夹）
│   ├── downloader.py  # 下载封装
│   ├── models.py      # 任务模型
│   └── config.py      # 配置
├── test_*.py          # 回归测试
└── BiliDownloader.spec
```
