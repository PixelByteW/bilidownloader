# 使用详解

## 解析链接

支持（可一次粘贴多行，每行一个链接）：

| 类型 | 示例 |
|---|---|
| 普通视频 | `https://www.bilibili.com/video/BV1xx411c7mD` |
| 多P视频 | 同上，自动展开全部分P；URL 带 `?p=2` 只下载第2P |
| 合集/剧集 | `https://www.bilibili.com/list/BV1xx411c7mD`（自动展开全部剧集） |
| 用户系列 | `https://space.bilibili.com/123456/lists/789?type=series` |
| 收藏夹 | `https://space.bilibili.com/123456/favlist?fid=123` |
| 短链 | `https://b23.tv/xxxxxx` |

坏链接自动跳过并标注行号，不影响其余链接。

## 批量导入

1. 把多个链接逐行粘贴到顶部输入框
2. 按 `Ctrl+Enter` 或点"解析"
3. 命名模板中的 `{n}` 按导入顺序编号（01 起，追加导入自动续号）

## 搜索过滤

解析出大量任务（如 564 集合集）时，在"搜索"框输入关键词：
- 匹配：分P标题、主标题、BV号
- 实时过滤，右侧显示"筛选出 N/总数"
- 过滤不影响任务勾选与下载

## 画质与编码

- 全局：顶部下拉框选择画质（自动=最高）、编码（AVC/H.264、HEVC/H.265、AV1）
- 单独调整：双击任务行，在弹出的窗口为该任务指定画质/编码
- 下载失败时会自动尝试降低画质档位重试

## 命名模板

| 变量 | 示例结果 | 说明 |
|---|---|---|
| `{title}` | 第一局 | 分P标题 |
| `{video}` | LPL比赛 | 主标题 |
| `{p}` | 1 | 分P序号 |
| `{p2}` | (空)/2 | 分P序号，单P为空 |
| `{quality}` | 720P | 实际画质 |
| `{codec}` | avc | 编码 |
| `{bvid}` | BV1xx | 视频ID |
| `{n}` | 01 | 导入顺序号 |

## 下载与并发

- 并发：同时下载的任务数（1-8），大合集建议 2-3
- 线程：单个任务的分片连接数（1-16，默认 4）
  - 不限速网络：8 线程最划算（实测 +12% 速度），16 无增益
  - 单连接限速（速度趴在 2-4MB/s）：线程拉到 8 效果明显
- 失败任务自动重试 1 次，再失败则跳过，不阻塞队列
- 高画质自动合并音视频（需 ffmpeg，打包版已内嵌）

## 常见问题

**下载到一半报错/变慢？** 检查网络与 B 站限流，适当降低并发。

**某些视频解析失败？** 部分地区 IP 会被 B 站降级，可尝试登录账号（设置 → Cookie）后重试。

**输出文件在哪？** 默认 `下载/BiliDownloader`，可在界面上改输出目录。
